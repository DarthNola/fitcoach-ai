# Web App Guidelines

- Use Vue 3 and TypeScript, following the project architecture in `../../docs/architecture/architecture.md`.
- Explain unfamiliar Vue concepts and keep changes focused so the project owner can learn from them.
- Before implementing a feature, inspect the existing app and agree on a plan.
- Validate user input and keep private credentials out of frontend code.
- Verify changes with the relevant checks when requested; report only checks that were run.
